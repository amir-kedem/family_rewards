# Family Rewards release notes

Each version lists the changes users can see and the Git revisions that reached the app. A short display version such as **2.1** identifies the release. The revision in **ניהול** identifies the exact build.

## 2.0.0-rc.1

### Initial candidate

- Added **ניהול משתתפים** to Parent mode. Parents can add children, edit profiles, and adjust points from a child’s row. Point adjustments require a reason and appear in history.
- Added a shared child emoji picker to onboarding and member management, with 24 presets and a custom option.
- Kept the balance overview and family goal together under **יתרות ויעדים**.

[View the tagged candidate](https://github.com/amir-kedem/family_rewards/tree/v2.0.0-rc.1)
